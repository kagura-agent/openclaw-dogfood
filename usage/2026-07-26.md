### 摩擦点
- **磁盘空间缓慢增长**: 84% 且无明显大文件源。需要排查 session 日志增长
- **npm view gitHead 字段为空**: `npm view openclaw@2026.7.1-2 gitHead` 返回空，无法通过此方式确认 hotfix 具体 commit 差异
- **proxy env 限制**: exec 工具禁止设置 HTTPS_PROXY 环境变量（Security Violation），需依赖系统全局配置

### Workarounds
- proxy: 直连可用，无需 workaround
- gitHead: 改用 `gh release list` + `gh api compare` 获取版本差异
- 磁盘: 暂无 action，待 server-health cron 专项跟进
