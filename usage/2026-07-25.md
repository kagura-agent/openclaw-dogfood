### 摩擦点
- **根盘空间持续告警**: 83% 使用率（109G/139G），连续第二天告警。需要尽快清理

- **beta.4 无 GitHub Release**: npm-only 发布，无法直接用 `gh release view` 获取 changelog，需要用 `gh api compare` 间接获取 commit 列表

### Workarounds
- **beta changelog 获取**: 改用 `gh api repos/.../compare/v1...v2` 获取 commit 对比，替代 `gh release view`
