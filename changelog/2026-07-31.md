## v2026.7.2-beta.5 新特性摘要（重点！）

基于 gh CLI 获取的完整 changelog（3908 merged PRs），以下是对我们最有价值的变化：

### 🆕 可以立即采用的新功能

1. **Session rewind & branching** — 可以从任意消息点回溯/分叉对话，跨 web 和 native 切换 transcript 分支。对我们调试长对话、回退错误决策很有用。(#110660, #110857)

2. **Scheduling 增强: `/loop` + 动态节奏 + gated script payloads** — per-job dynamic cadence 可以让 cron 任务根据运行结果自动调整频率；`/loop` 提供交互式循环命令。对我们的 cron-heavy 使用模式（version-check、heartbeat 等）是重要升级。(#110978, #111112, #114328)

3. **Durable channel delivery** — 消息在 gateway 重启和本地 crash 后可恢复，覆盖 Telegram、Signal、Slack、Discord 等。我们的 Discord 投递偶尔在重启后丢消息，这个直接解决痛点。(#108656, #107246)

4. **Fast active-memory recall + guided imports** — 更快的 memory 召回，加上从 Claude Code/Codex/Hermes 导入记忆的引导流程。我们 memory 使用量大，性能提升有感。(#108043, #110597)

5. **Interactive MCP Apps & dashboards** — 可以 host ticketed MCP Apps 并固定到 dashboards。对我们未来构建交互式工具面板有潜力。(#109851, #110451)

### 🔧 修复了我们遇到过的痛点

6. **CJK compaction 修复** — 终于在 compaction 估算中正确计算 CJK 文本宽度，`no_compactable_entries` 当作良性跳过。我们一直遇到中文消息 compaction 异常的问题，这个是直接对症下药。(#114386, #114449)

7. **Cron 可靠性大修** — 恢复 one-shot 和 startup catch-up jobs，保留 script state 跨重启，修复 job 被慢批次阻塞的问题，trim job IDs。我们的 cron 系统是核心基础设施，这些修复极其重要。(#107236, #110351, #111292, #114421)

8. **Channel delivery 丢消息修复** — 特别修复了 Telegram/Discord/iMessage/WhatsApp 在 crash 或重启后丢流量的问题，恢复中断 turn 后的 assistant context。(#107288, #113368, #110274)

9. **SQLite 数据安全** — 在 transcript eviction 前 commit session indexes，防止 maintenance race 导致数据丢失，crash-recoverable snapshot publication。(#108378, #113367)

### ⚡ 值得关注但暂不采用的

10. **Claude Opus 5 支持** — 已加入 catalog 和 runtime。等 stable 后可以测试切换。(#113391)

11. **Wear OS companion** — 手表端支持，包括 agent 选择、Talk 控制等。目前我们不用但说明多端支持在扩展。(#108781)

12. **Meetings: Teams/Zoom/Google Meet** — 默认启用会议插件，自动收集持久会议记录。未来可能用于会议总结场景。(#109964, #111048)

13. **Guided setup + local inference** — llama.cpp/Gemma 本地推理、模型下载。对离线场景有价值但我们目前依赖云端模型。(#108604)

14. **Structured questions & approvals** — agent 可以在 web/channel/macOS 上发送结构化问题卡片，approval 获得推送通知和历史记录。(#85954)
