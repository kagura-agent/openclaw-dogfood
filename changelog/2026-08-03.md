## 🆕 v2026.7.2-beta.7（2026-08-02）— 相比 beta.6 的增量

beta.6 → beta.7 仅间隔 1 天，变化集中在 channel delivery 和 session 稳定性修复：

### 🔧 修复了我们可能遇到的痛点

1. **TUI session 状态保持** — 切换 session 和重连后保持 TUI 状态，不再丢失。我们偶尔用 TUI 调试时遇到过 session 切换后状态丢失。(#117260)

2. **Channel delivery 额外修复** — Telegram ingress outcome 保持 (#116773)、新增 channel delivery 修复 (#116726; related #116688)。虽然我们主要用 Discord，但 durable delivery 基础设施是共享的，直接受益。

3. **Install/upgrade 额外修复** — 又一个安装稳定性补丁 (#116345)，升级安全感进一步提升。

## v2026.7.2 完整版本亮点回顾（对我们最重要的 10 项）

### 🆕 立即可采用的新功能

1. **Session rewind & branching** — 可以从任意消息回退/分叉对话。ACP 工作流中经常想 "回到那一步重来"，这个功能直接解决。
2. **Scheduling 增强（/loop + dynamic cadence + script payloads）** — 我们重度使用 cron，动态节奏和脚本触发器能让 cron job 更智能。
3. **Memory 增强（fast recall + cross-conversation + 导入）** — 从 Claude Code/Codex/Hermes 导入 memory，跨会话召回更快。
4. **MCP Apps & dashboards** — 可以把 MCP App 钉在 dashboard 上，从 channel reply 打开。trading-agents 的分析面板可以用这个。
5. **Automations 重命名** — cron → Automations，UI 更友好，CLI alias 兼容。

### 🔧 修复我们遇到过的痛点

6. **Cron 可靠性修复** — 恢复 one-shot/startup catch-up jobs，修复重启后 script state 丢失，解决 job 被慢 batch 阻塞的问题。这修了我们 08-01 遇到的 gateway restart 打断 cron 的问题。
7. **CJK compaction 修复** — CJK 文本 compaction 估算不准确的问题终于修了。我们大量使用中文，这个直接受益。(#114386)
8. **Provider 可靠性** — Claude CLI stall recovery、Anthropic Retry-After 遵守、stalled response body 限制。
9. **ACP/Codex runtime** — Code Mode repair 限制为单次、promoted approval 不再阻塞 unattended runs。

### ⚡ 值得关注但暂不采用的

10. **Fish Audio S2.1 语音** — 流式语音合成 + voice notes。播客 skill 未来可用。
