## 🆕 新发布: v2026.7.2-beta.6（2026-08-01）

距上一个 beta.5 (07-28) 仅 4 天，说明开发节奏恢复正常。以下是 beta.6 中**相对 beta.5 新增/变化**的重点：

### 🆕 对我们有用的新功能

1. **Fish Audio S2.1 语音合成** — 托管式流式语音合成，支持 voice notes、voice discovery 和电话功能；macOS Talk 支持本地 Fish S2 Pro 参考声音流式合成。未来如果做播客/语音场景可直接采用。(#115790)

2. **Automations 重命名** — `cron` agent tool 和 CLI/UI 界面统一更名为 "Automations"，保留 CLI alias 兼容。我们大量使用 cron，UI 体验更友好了。(#114841, #114854)

3. **Control UI setup → Custodian** — 验证模型设置后可直接进入 Custodian 流程，说明 web app 已可用不需要 channel，并提供可选的 Channels 引导路径。新用户 onboarding 更顺畅。(#116078, #116079)

4. **Buzz 消息通道** — 新增 Buzz plugin，保留 Markdown 和结构化 room content，支持 room/thread-scoped typing indicators 和 reconnect-safe 生命周期。(#116096, #116194)

5. **DuckDuckGo 搜索 → 插件化** — 移出 core 进入 plugin boundary，provider ownership/安装/运行行为更独立。对我们自定义搜索配置有帮助。(#116740)

### 🔧 修复了我们遇到过的痛点

6. **Agent/Codex runtime 修复** — 限制 Code Mode repair 为单次校正 turn，保留有效 native Codex 控制，防止 promoted approvals 阻塞 unattended runs。我们 ACP 流程中偶遇 approval 卡住的情况，这个直接修复。(#115729, #107588, #116117)

7. **Install/upgrade 稳定性** — 修复 TypeBox package removal 后的 production install 恢复、plugin config 在升级时修复、外部 web-search plugins 在新安装上的发现等 17 个安装问题。升级安全感大增。(#114090, #114215, #116333)

8. **Provider 可靠性** — 恢复 stalled Claude CLI sessions 不丢 native cache continuity、稳定 Ollama/LM Studio 发现、绑定 stalled response bodies。我们偶遇 Claude provider 超时后 session 失效的问题。(#113078, #114397, #114582)

9. **Platform 可靠性** — 防止 user/system systemd 双重 Gateway ownership、修复 debug-proxy response backpressure、preserve Windows PATH delimiters。我们 systemd 管理下的稳定性受益。(#116162, #114076)

### ⚡ 值得关注但暂不采用的

10. **Kimi K3 模型** — 新增到 catalog。(#113633)

11. **GPT Live realtime** — 支持 Platform API 认证路径的实时对话。等 stable 后可测试。(#113909)

12. **安全加固** — 阻止 channel allowlists 授予 owner 权限、关闭伪造 marker/web-search boundary bypass、阻止非 owner ACP session 暴露等 14 项安全修复。(#107403, #110417, #110745)
