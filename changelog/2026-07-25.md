## 🆕 Beta.4 新特性摘要（beta.3 → beta.4 增量）

### 🆕 对我们有用的新功能

1. **Cron 心跳改为数据库存储** (`feat(cron): database-backed heartbeat monitor scratch replaces HEARTBEAT.md`)
   - 心跳状态从 HEARTBEAT.md 文件迁移到 SQLite，减少文件 I/O，提高可靠性
   - 对我们：我们重度依赖 cron（12+ jobs），这直接提升 cron 基础设施稳定性

2. **Claude 原生工具请求转发为 Gateway 审批** (`feat(agents): relay Claude native tool requests as Gateway approvals`)
   - Claude Code 的原生工具调用现在可以通过 Gateway 审批流程控制
   - 对我们：使用 ACP Claude Code 时能获得更好的安全控制

3. **百万 token 上下文需要显式 opt-in** (`feat(openai): make million-token context an explicit opt-in`)
   - 不再默认使用百万 token 上下文，需要显式启用
   - 对我们：控制成本，避免意外高 token 消耗

4. **Session 可见性和成员管理** (`feat(sessions): visibility states, membership, and server-enforced participation`)
   - Session 现在有可见性状态和成员权限控制
   - 对我们：多 channel 部署时更好的 session 隔离

5. **Session 草稿模式** (`feat(sessions): drafts UX — create-as-draft, promote, admin ghost treatment`)
   - 可以创建草稿 session，准备好后再激活
   - 对我们：可用于准备复杂的 cron task 或工作流

6. **自动收集会议转录** (`feat: auto-collect durable meeting transcripts`)
   - Teams/Zoom 会议结束后自动收集转录
   - 对我们：如果未来用 OpenClaw 管理会议流程，这是基础功能

### 🔧 修复了我们遇到/关注的痛点

7. **Cron claim 竞态修复** (`fix(cron): claim benign same-generation session updates`)
   - 修复 cron session 更新时的 claim 冲突
   - 对我们：直接影响我们的 12+ cron jobs 稳定性

8. **Ollama reader lock 释放** (`fix(ollama): release reader lock when parseNdjsonStream exits early`)
   - NDJSON 流提前退出时释放 reader lock
   - 对我们：如果切换到本地 Ollama 模型时的稳定性保障

9. **Memory 维护转隐藏** (`fix: hide memory maintenance turns from chat`)
   - 内存维护操作不再在聊天中显示
   - 对我们：减少 channel 中的噪音消息

10. **SQLite 3.51 兼容** (`fix(state): support SQLite 3.51 migration`)
    - 支持 SQLite 3.51 的 migration 变更
    - 对我们：系统升级后的兼容性保障

### ⚡ 值得关注但暂不采用的

11. **Control UI 隐身 session** (`feat(gateway): incognito sessions for the web Control UI`)
    - Web UI 上可以创建隐身 session
    - 暂不需要，但是安全/隐私场景有用

12. **Teams/Zoom 会议插件默认启用** (`feat: enable Teams and Zoom meeting plugins by default`)
    - 开箱即用的会议集成
    - 我们目前不用会议插件，但值得关注

13. **多用户 session 聊天记录重构** (`feat(ui): restructure chat transcript for multi-user sessions`)
    - 多人 session 的 transcript 展示优化
    - 我们主要是单 agent 使用，暂不直接受益

14. **归档归因** (`feat(sessions): archive attribution (archivedBy)`)
    - 记录是谁归档了 session
    - 运维审计有用，暂不紧急

15. **Dashboard 标题显示连接状态** (`feat(ui): mirror active destination and connection state in the dashboard title`)
    - 一目了然看到连接是否正常
    - 下次用 Control UI 时自动受益
