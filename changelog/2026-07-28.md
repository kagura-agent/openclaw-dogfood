## v2026.7.2 特性预览（来自 beta.3 changelog）

### 🆕 对我们有用的新功能

1. **Skill Workshop 自动审批** — agent 发起的 apply/reject/quarantine 不再需要额外 approval prompt，`approvalPolicy: "pending"` 变为 opt-in。减少我们日常 skill 管理的手动摩擦。
2. **Cron 历史 API** — 从 task ledger 提供 scheduled-run history，可查询 cron job 的执行记录。我们有 12+ cron jobs，这对排查失败和统计运行状态非常有用。
3. **Skill Workshop 历史回顾** — 自动扫描过往 session 寻找 conservative skill ideas，存为 pending proposals。帮助我们从使用模式中自动发现可复用流程。
4. **MCP isolation** — MCP server 连接按 session 隔离。提升多 session 并发时的安全性和隔离性。
5. **Gateway control-plane rate limiting** — 30/min per-method buckets，防止 runaway loop 同时保持交互式操作响应。

### 🔧 修复了我们遇到过的痛点

6. **Cron lifecycle conflict retries** — 修复 post-execution claim conflicts 导致的 completed messages/tools 重播问题。我们的高频 cron 场景直接受益。(#108428)
7. **Gateway restart admission 不再卡住** — 防止 restart 时 admission 楔入，我们之前遇到过 restart 后 gateway 无响应的情况。
8. **Codex dynamic tool outcomes** — Skill Workshop 结果不再被错误显示为 failed calls。(#107684)
9. **Signal shutdown delivery** — 关机前 drain ingress，不再丢消息。

### ⚡ 值得关注但暂不采用的

10. **Remote coding sessions** — cloud worker 上运行 Codex/Claude sessions。我们目前本地运行够用，但 cloud offload 是未来方向。
11. **OpenAI GPT-5.6 defaults** — 新安装默认用 GPT-5.6 Sol，现有配置不变。等稳定后可评估切换。
12. **Managed worktrees cleanup** — Settings 中配置 worktree 清理限制（count/size），可帮助控制磁盘增长。
