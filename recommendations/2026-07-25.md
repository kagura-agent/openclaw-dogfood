# 采用建议 — 2026-07-25

## 基于 2026.7.2-beta.4 的新发现

### 高优先 — beta.4 stable 后立即采用

#### 1. Cron 心跳数据库化
- **功能**: `database-backed heartbeat monitor scratch replaces HEARTBEAT.md`
- **场景**: 我们有 12+ cron jobs，HEARTBEAT.md 的文件 I/O 在高并发时可能是瓶颈
- **行动**: beta.4 stable 后升级即自动生效，无需配置变更
- **风险**: 低，内部实现变更

#### 2. 百万 token 上下文 opt-in
- **功能**: `make million-token context an explicit opt-in`
- **场景**: 部分 cron job（server-health, cove-patrol 等）不需要大上下文
- **行动**: 审查各 cron job 的 contextTokens 设置，确保合理
- **当前状态**: 已有部分 job 设为 200k，但有些仍是 1M 默认值

#### 3. Claude Gateway 审批流
- **功能**: `relay Claude native tool requests as Gateway approvals`
- **场景**: ACP Claude Code sessions 的安全控制
- **行动**: 测试 Claude Code 工具调用的审批流，评估是否影响工作效率

### 中优先 — 观察后决定

#### 4. Session 可见性管理
- **功能**: `visibility states, membership, and server-enforced participation`
- **场景**: Discord 多 channel 部署，防止 session 内容跨 channel 泄漏
- **行动**: 待 stable 后评估是否需要为敏感 channel（finance, server-health）设置可见性限制

#### 5. Session 草稿模式
- **功能**: `create-as-draft, promote, admin ghost treatment`
- **场景**: 准备复杂工作流时先创建草稿，调试完成后再激活
- **行动**: 考虑用于新 cron job 的开发测试阶段

### 低优先 — 记录备查

#### 6. 会议插件和转录
- Teams/Zoom 默认启用 + 自动转录收集
- 目前不使用会议功能，但如果未来需要 AI 参与会议则是关键基础

#### 7. Control UI 改进
- 隐身 session、Dashboard 连接状态、多用户 transcript 重构
- 主要用 Discord channel 交互，Control UI 偶尔使用，自动受益
