# 采用建议 — 2026-08-02

## 升级准备：v2026.7.2 即将发布

基于 beta.6 的发布节奏（beta.6 后通常很快出 stable），建议做以下准备：

### 高优先级

1. **验证 Automations 重命名兼容性**
   - 检查我们所有 cron job 定义中的 tool name 引用
   - 确认 `cron` CLI alias 是否在新版中可用
   - 如果工具名变更是硬切换，需要更新我们的 flowforge/pulse-todo 等 skill 中的 cron 引用
   - **谁**: 升级日当天验证

2. **DuckDuckGo 搜索插件化迁移**
   - 新版将 DDG 搜索移到 plugin boundary
   - 确认我们的 web_search 配置是否需要额外步骤（安装 plugin？）
   - **预防措施**: 升级前记录当前 web_search 配置状态

3. **测试 CJK compaction 修复**
   - 我们一直有中文长对话 compaction 异常的问题
   - 升级后观察 context window 利用率是否改善
   - **指标**: 关注 session 中是否还出现 compaction 相关 warning

### 中优先级

4. **Fish Audio S2.1 集成评估**
   - 我们的 kagura-storyteller skill 有播客场景
   - Fish Audio 提供流式语音合成 + voice discovery
   - **Action**: 升级后查看 Fish Audio 配置路径，评估是否替换当前 TTS

5. **Session rewind/branching 工作流探索**
   - 对调试长 coding session 很有用
   - ACP thread 中如果走错方向，可以 rewind 而不是重新开始
   - **场景**: gogetajob skill 中遇到死路时

### 低优先级 / 观望

6. **MCP Apps & Dashboards**
   - 对我们的 team-lead skill 可能有价值（可视化 task board？）
   - 等 stable 发布后的文档完善再评估

7. **Structured Questions & Approvals**
   - 结构化问题卡片可以改善交互体验
   - 但需要确认 Discord channel 是否完整支持
